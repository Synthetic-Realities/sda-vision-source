About this local installation

SDA stands for Synthetic-media Discourse Analysis. Explore AI-generated and traditional media through model assessments, Content Credentials, supporting file observations and group discussion.

An academic research project of Synthetic Realities, led by Dr Sam Martin, Smart Data Research UK (UKRI) Fellow (Grant number UKRI4010), Manchester Metropolitan University (MMU). ORCID: 0000-0002-4466-8374.

This work was supported by Smart Data Research UK, a UKRI investment; Grant number UKRI4010.

Your working profile

The banner at the top of the app identifies the active profile. Research app — live analysis supports local file selection, batches and configured analysis. Community Workshop and Developer are two views of the same selected item. The separately configured Conference profile supports presenter-operated live checks of its reviewed example list.

The public web demo provides prepared examples and saved results. It is available as a recording and presentation fallback.

Media and checks

Images, sampled video frames, PDF pages, slide images and audio transcripts have distinct analysis scopes. PowerPoint previews use local LibreOffice and can be explored inline in Community Workshop or in the enlarged Developer viewer. Previewing slides is separate from running an analysis.

Reports show completed checks, their scope and evidence. Inconclusive model replies remain undecided; ratings are not calibrated probabilities. Transcript assessments and optional audio descriptions appear separately. AI-origin detection from the sound itself is outside this workflow. Relationship graphs map analysis relationships or image similarity; distribution history is not assessed.

Processing and saved work

Live checks send selected media or prepared images/text to the configured providers using your API accounts. The analysis controls describe the material sent and available consent choices. Provider terms, retention and charges apply. Keys stay on the local server for provider authentication.

Research-mode retention is shown in the app's privacy details: when enabled, unencrypted reports, extracted text, filenames and thumbnails are saved in dev_runs/ until deleted. The Conference profile returns reports to the browser without that research-run storage. Media preparation can create temporary local files; interrupted processing may leave files to clean up.

Download reports and session notes to keep your work. Workshop responses remain separate from model scores. Second Opinion and Google Lens open the selected external service, where you choose any material to share. The local app's footer explains the active profile's storage and optional-send details.

Facilitator field guide

Explore the guide and activity previews, or open the seven-page guide PDF, version 1.5. The guide supports facilitators, educators and researchers leading Notice, Discuss, Check and Reflect.

Hearsay Harbour game

Game → Demo opens the Hearsay Harbour island game, hosted online on GitHub Pages. Its prepared picture packs use scripted findings for teaching. Game → Dev mode introduces the separate local Dev Studio for creating packs, with screenshots, setup instructions and the game’s downloads and Concept DOI.
