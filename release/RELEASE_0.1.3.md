# SDA Vision 0.1.3

Release date: 16 October 2026. The researcher approved publication after reviewing
the local recorded demo. Software 0.1.3 and guide resources 1.7 are separately versioned.

## Included

- Software 0.1.3, with the full source distribution scope retained.
- Facilitator field guide 1.7 and its one-page participant quick guide.
- Side-by-side SynthID Detector and OpenAI paste-results boxes in the recorded demo.
- Eleven selected originals, with unchanged media and saved analysis records.
- Explicit SDA Vision metadata in newly generated PDF and PowerPoint reports.
  In the recorded-demo candidate, only document metadata was refreshed in the
  eleven PDF and eleven PowerPoint downloads; their content was preserved.

The recorded findings retain their original software/model versions and dates.
The export's creation date describes preparation of that document, not a new
analysis. Pasted external replies remain separate from model scores.

## Delivery Scope

The workshop edition uses prepared examples and pre-recorded findings.
Participant media uploads into SDA are absent. External checks require the
agreed session arrangements; discussing prepared replies is supported.
The separately distributed Research app retains its configured live-analysis
features. These are distinct delivery settings.

Existing Concept DOI series are retained: software 10.5281/zenodo.23008102;
guide resources 10.5281/zenodo.23008188. Each series retains its existing published
versions. See the linked record for the latest deposited version.

This change does not revise provider prompts, scoring, trust policy or the
scientific method. Website deployment repositories are separate from the full
public source distribution. Changing their visibility depends on retaining
compatible hosting for sdavision.io.
