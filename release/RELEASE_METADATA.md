## Software description

SDA Vision (Synthetic-media Discourse Analysis) supports researchers, educators and community facilitators examining how AI-generated and traditional media are made and how its claims can be discussed. A local Python application and browser interface bring together model interpretations, content-credential findings, supporting file observations and human reflection. Images, sampled video frames, PDF pages, PowerPoint slides and audio transcripts have distinct analysis scopes. Researcher-operated external checks use the configured provider accounts and explicit consent where offered.

Community Workshop follows Notice, Discuss, Check and Reflect. Developer provides detailed findings, batches and exports. The public website uses approved examples and saved results; installed Research mode supports local file selection and configured live analysis. Uploaded PowerPoint slide rendering uses optional local LibreOffice.

Verdicts follow the versioned agreement rules in the method records. Inconclusive replies remain undecided; ratings are not calibrated probabilities. Transcript interpretation and optional audio descriptions have separate scope. AI-origin detection from the sound itself is outside this workflow. Graphs show analysis relationships or image similarity; distribution history is not assessed.
