# SDA Vision: Participant Quick Guide

Version 1.7, 16 October 2026. For the recorded, prepared-example demo.

## Already Have A Reply?

Return to **Check** in SDA. In the **Evidence box**, find **External checks**.
Paste the full reply into **SynthID results** or **OpenAI results**, under the
service you used. That is the whole return step: your text is kept immediately
in this browser session. No media upload back into SDA or extra save form is
needed.

## Trying A Check Together

| Step | What to do |
| --- | --- |
| 1. Open the example | Choose the prepared example agreed with your facilitator. In **Check**, select **Open recorded findings** if they are not already open. |
| 2. Choose a checker | In **External checks**, SynthID Detector and the OpenAI image checker appear together. They stack on smaller screens. You can use either, both where available, or follow the facilitator's demonstration. |
| 3. Check the prepared file | Use **Download example**, then **Open SynthID Detector** or **Open OpenAI checker**. On that service, choose the downloaded file. For slides, choose **Material for SynthID** first, then **Download selected image**. |
| 4. Return and paste | Copy the complete reply, including any error message, into the matching **SynthID results** or **OpenAI results** box. |

Where external uploads are authorised by the session arrangements, Google receives a file sent to SynthID Detector;
OpenAI receives an image sent to its checker. The upload includes retained
metadata. Each service uses your account there, its current terms and any
charges, separately from SDA's API accounts. Opening a link sends no media.
Use the prepared example agreed for this activity; watching the facilitator
or discussing a previously recorded reply is also an option.

## Which Material?

- **Image:** use the prepared image. The OpenAI shortcut is enabled for image
  examples.
- **PDF or slides:** SynthID uses a prepared page or slide image. Select the same
  slide when pasting its reply; SDA keeps one SynthID reply for each selected
  material. Keep the complete document alongside it for context.
- **Audio or video:** the demo offers its prepared original for SynthID. Review
  the service's current file limits and the scope of its reply there. The OpenAI
  shortcut is labelled **OpenAI checker: images only**.
- A separately checked image reply can go in **OpenAI results** with its page or
  frame name. That box is a single note for the example.

## Keep Your Notes

Choose PDF, PowerPoint or CSV under **Take the findings with you**, then use the
download button. Do this before changing examples, reloading, closing the page
or starting a new session. In Developer, use **Download session with your
notes**; **Download original recorded report** contains the earlier findings.

Your pasted replies stay separate from the recorded model scores. SDA retains
the text you enter; it does not independently confirm the file submitted or the
service's response. An error can be kept as an error; if a check is skipped,
leave its box empty. Compare each reply's stated coverage with the source and
the group's observations.

For this demo, use the dedicated **SynthID Detector** rather than the former
Gemini chat shortcut. The Google Gemini model findings in the results table
remain part of the recorded analysis.
