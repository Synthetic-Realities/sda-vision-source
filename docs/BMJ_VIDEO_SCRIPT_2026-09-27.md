## Recording Notes

- Use the confirmed introductory name/affiliation above. The spoken opening is
  shorter for timing; the title card retains she/her, UKRI and the full university name.
- Use one primary example cleared for public video inclusion. A second example
  or short batch provides a quick comparison; the complete mixed-format pack is
  unnecessary for this recording. Retain the appropriate credit in-frame or in
  the supplied description.
- Use neutral participant filenames such as `Example-001.png`; keep OA/NLM and
  the full generator details in the private source key. Introduce any source
  reveal after the first-impression moment, subject to required attribution.
  Keep the completed private source key outside the recorded view.
- Keep the interface legible in landscape. A 1920×1080 capture is a proposed
  production setting, not a requirement supplied by BMJ. Test the actual capture
  application, microphone and export before the final take.
- If using saved findings, introduce them as a recorded analysis. If showing a
  fresh analysis, agree the exact original, provider accounts and run allowance
  and give the processing consent before the request. No fresh provider run has
  been executed by this implementation work.
- If the result shows failure or disagreement, describe that state. Introduce
  any saved fallback with its original analysis date and model labels.
- Crop/edit only to improve pacing and legibility. Preserve the association
  between the selected original and its displayed findings, dates and model names.
- Record a short microphone/screen test, then a timed rehearsal. If the full take
  exceeds 2:30, shorten the introduction or batch cutaway rather than speeding up
  the narration. Review the final recording before sending it to BMJ.
